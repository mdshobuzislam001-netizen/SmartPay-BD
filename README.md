# SmartPay BD
Flutter Android starter for a lawful digital-payment service.

Current version is an app shell only. It does not process money or connect to wallets.
For live payments, obtain an approved merchant/payment-gateway integration, build a secure backend, verify every transaction server-side, and meet applicable legal requirements. Never ask users for wallet PINs or OTPs.

Build APK:
- `flutter pub get`
- `flutter build apk --release`
- Output: `build/app/outputs/flutter-apk/app-release.apk`
